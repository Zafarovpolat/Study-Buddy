## 💰 Оценка затрат

### Инфраструктура (месяц)
| Сервис | Использование | Стоимость |
|--------|---------------|-----------|
| **Render.com** (Backend) | Web Service, 512 MB RAM | $7-25 |
| **Supabase** (PostgreSQL) | Free tier (500 MB) | Free → $25/мес |
| **Gemini API** | ~0.01$/1K tokens | ~$5-15/мес |
| **Telegram Bot** | WebHook, бесплатно | Free |
| **Итого** | | **~$12-50/месяц** |

---

## ⚠️ Известные ограничения

1. **Gemini API rate limits** — при высокой нагрузке возможны 429 ошибки
2. **Размер файлов** — максимум 20 MB
3. **Формат .doc** — не поддерживается, только .docx
4. **Группы** — максимум 50 участников
